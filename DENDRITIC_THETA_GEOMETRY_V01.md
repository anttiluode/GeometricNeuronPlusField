# Dendritic theta geometry v0.1 — the clock is spatial inside the neuron

The theta/gamma discussion changes substantially once the rhythm is not treated as one scalar clock broadcast uniformly to the whole cell.

A 2024 in-vivo voltage-imaging study measured membrane potential at many locations across individual CA1 pyramidal-cell arbors in awake mice:

Z. Liao et al., **“Functional architecture of intracellular oscillations in hippocampal dendrites,”** *Nature Communications* 15, 6295 (2024), DOI `10.1038/s41467-024-50546-z`.

The empirical result that matters here is geometric:

- theta-band membrane potential was detectable across most recorded dendritic regions;
- theta phase changed systematically with position along the basal-to-tuft axis;
- the pooled phase gradient was about **-7.9 degrees / 100 micrometers**;
- dendritic depolarizing-event phase showed a comparable spatial gradient;
- the paper describes the intracellular theta-band membrane-potential pattern as a **traveling wave across the dendritic tree**.

This is not evidence for adjoint learning. It is evidence that the slow oscillatory context of a real pyramidal neuron is itself a **spatially indexed field over morphology**.

## Why this matters for GeometricNeuronPlusField

Our current engineering abstraction has mostly used a global gate:

```text
m(t)
```

applied everywhere with one phase.

The in-vivo observation suggests that a more biologically relevant local gate would look like

```text
m(x,t) = f(theta*t + phi(x))
```

where `phi(x)` varies with location in the arbor.

That changes the role of morphology.

The dendritic tree would not merely determine the transfer operator for the fast electrical signal. It would also be embedded in a slower spatial phase coordinate that changes **when** each region is permissive for coincidence, propagation, inhibition, or plasticity.

A schematic becomes

```text
fast input/return fields:      psi(x,t), mu(x,t)
slow phase field:              theta(x,t)
local structural signal:       gate(theta(x,t)) * overlap(psi,mu)
```

The important point is not the symbol theta. It is that the gate is now **geometric**.

## This is closer to the original Geometric Neuron intuition

The original line kept returning to the idea that morphology and an electrical field should not be separated into "wire" and "signal."

The current repo already established in its model that:

```text
geometry -> modal dynamics -> local consequence
```

and that the same reciprocal geometry can route a returned structural derivative.

The Liao et al. observation adds a real-neuron fact of a different kind:

```text
morphological position <-> oscillatory phase
```

inside one cell.

So a future biological analogue need not require the dendritic tree to calculate a global transform or the soma to digitally address branches. A branch can have a different temporal relationship to a global/network rhythm simply because of where it sits in the cell and which inputs/inhibitory populations act there.

That is a plausible physical addressing mechanism.

## Important caveat

The observed phase gradient need not be generated by passive propagation through the dendritic cable. CA1 receives strongly layer-specific, phase-structured excitation and inhibition, and active membrane conductances also shape intracellular theta.

Therefore do **not** infer

```text
dendrite length causes theta phase delay
```

from the imaging result.

What is established is the spatial phase organization itself.

For our purpose that is enough to motivate the next experiment.

## Next experiment — spatial phase gate

After the global-gating hostile controls, freeze a family of local gates

```text
m_e(t) = square(omega*t + alpha*d_e + phi0)
```

where `d_e` is graph distance or a signed basal/root/source coordinate and `alpha` controls a phase gradient.

Compare:

```text
A. global phase                 alpha = 0
B. smooth graph-distance phase  alpha != 0
C. shuffled local phases        same phase histogram, geometry destroyed
D. random independent phases
```

Apply the gate only to the **local forward x return overlap / structural update**, not by pretending theta physically multiplies the soma return waveform.

Primary questions:

1. Does a smooth phase gradient preserve more of the exact structural direction than shuffled phases at the same duty cycle?
2. Can spatial phase reduce interference between different source histories or graph-mode pairs?
3. Does an optimal `alpha` scale with the arbor's modal/propagation time scale?
4. Does the useful gradient track geometry or merely the number of independently phased local gates?

If smooth and shuffled phase fields are equivalent, the geometric-theta idea dies in this model.

If smooth phase wins on held-out bodies, the next question is mechanistic: which spatial modes are being separated by the phase gradient?

## Wall sentence

> **A real CA1 dendritic tree does not sit under one theta clock: intracellular theta phase is spatially organized across the arbor. That makes oscillatory phase a candidate local coordinate for when geometry can be read or changed, without implying that theta itself carries an adjoint error.**
