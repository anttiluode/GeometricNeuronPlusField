# Reciprocal wave credit and photonic in-situ backpropagation

The exact time-reversal identity in `RECIPROCAL_ADJOINT_V01.md` is not an isolated mathematical curiosity. It belongs to the established **in-situ backpropagation / adjoint-variable** literature for reciprocal physical networks.

## Closest prior art

Tyler W. Hughes, Momchil Minkov, Yu Shi, and Shanhui Fan, **“Training of photonic neural networks through in situ backpropagation and gradient measurement,”** *Optica* 5(7), 864–871 (2018), DOI `10.1364/OPTICA.5.000864`.

That paper explicitly names its physical gradient procedure the **time-reversal interference method (TRIM)**. It derives a photonic analogue of backpropagation from the adjoint-variable method and shows that gradients of tunable physical parameters can be recovered from physically propagated forward/adjoint fields using in-situ intensity/interference measurements.

Sunil Pai et al., **“Experimentally realized in situ backpropagation for deep learning in photonic neural networks,”** *Science* 380(6643), 398–404 (2023), DOI `10.1126/science.ade8450`.

That experiment trained a three-layer four-port silicon photonic network using bidirectional propagation through a programmable Mach–Zehnder-interferometer mesh. Forward, backward/adjoint, and interference/sum measurements supplied phase-shifter gradients; the authors also evaluated an analog-domain gradient-measurement/update path.

## What our result independently recovered

For the mature linear FunctionalArbor medium,

```text
v[n+1]   = a v[n] + dt H psi[n] + dt s[n]
psi[n+1] = psi[n] + dt v[n+1]
```

with reciprocal spatial operator `H=H^T`, the exact discrete adjoint combination that appears in the bond gradient obeys the same second-order damped recurrence after reversing task time.

Thus the exact bond sensitivity can be generated by:

```text
1. run the task field forward;
2. form the objective-derivative waveform at the soma;
3. reverse that waveform in task time;
4. inject it from the soma through the same reciprocal medium;
5. locally multiply forward and returned field differences across each bond;
6. integrate the overlap to obtain dJ/dk_e.
```

Fresh seeds 264-275 established numerical identity with the algorithmic discrete adjoint to floating-point precision (`~1e-15` map error).

This is therefore best described as an independent recovery of the **same physical adjoint / time-reversal-interference principle** used by photonic in-situ training, specialized to this damped time-domain wave/scattering model.

The distinction matters. Hughes/Pai work primarily with coherent optical transfer at a carrier frequency and programmable phase shifters. Our toy has an explicit second-order temporal waveform, damping, restoring force, local conductances, and a soma objective. The common object is the reciprocal physical adjoint and local forward/backward overlap — not an identical device equation.

## Reciprocity is the enabling condition

The cheap physical backward pass exists because the spatial operator is reciprocal/symmetric. In a nonreciprocal medium the desired adjoint generally requires the transposed/adjoint operator rather than simply reusing the forward device.

A useful engineering trade is:

> **Reciprocity buys direct reuse of the physical forward operator for gradient transport.**

Do not turn that into the stronger universal statement that reciprocity forbids every temporal arrow. A causal damped reciprocal system still has causal dynamics, and temporal-order discrimination can arise from source geometry, history, nonlinear observation, or active state. What reciprocity constrains is which directional/antisymmetric operations the passive operator itself can realize and whether the same hardware implements its adjoint.

## Biological scope

This result weakens a direct claim that a biological neuron should perform exact same-medium adjoint learning, but it does not erase every biology comparison.

Chemical synapses between neurons are strongly directional and therefore do not provide a reciprocal network operator that can simply be run backward. However, passive intracellular cable coupling within a dendritic/axonal tree is a different object and is approximately reciprocal in its linear axial component; active ion channels, boundary conditions, synaptic conductances, and spike initiation then make the effective biological system nonlinear and state-dependent.

So the correct boundary is:

```text
exact reciprocal in-situ adjoint mechanism
    -> strong engineering / photonic / acoustic relevance
    -> not established as a neuronal learning mechanism
```

rather than “all neuron analogies are dead.”

## Hardware interpretation

The repo's most immediate hardware reading is now a **trainable reciprocal wave/scattering medium**:

```text
continuous local couplings rho_e
        ↓
physical transfer/scattering operator
        ↓
interferometric local objective
        ↓
physical reciprocal adjoint pass
        ↓
local forward × backward gradient measurement
        ↓
local coupling update
```

The closest experimental precedent uses programmable MZI meshes, not the exact grid/tree geometry used here. The shared device principle is a reciprocal linear interferometric network with tunable local parameters and physically measurable adjoint gradients.

## Device-error tests need a compiler map first

Pai et al. explicitly report practical errors from phase measurement, optical loss, thermal crosstalk, optical I/O error, and photodetector noise. Those are the right *classes* of degradation to care about.

But a silicon phase-shifter error measured in radians cannot yet be copied numerically onto this model's bond conductance. `rho_e` is not an MZI phase. Before claiming a hardware-tolerance number, we need an explicit mapping

```text
model coupling rho_e
        <->
physical device control / scattering parameter
```

for the proposed implementation. Until then, arbitrary “0.025 rad on rho” tests would look hardware-realistic while actually being dimensionally meaningless.

## What becomes the important benchmark

Once the topology/coupling field is differentiable and the gradient can be obtained in situ, the scientific question is no longer whether it can be trained.

It is:

> **Does constraining the dynamics to a spatially local reciprocal wave/scattering geometry buy useful computation per trainable physical parameter compared with a conventional unconstrained temporal filter model?**

That requires a matched-parameter benchmark, not another demonstration that gradient ascent follows a correct gradient.

`RANDOM_FRONTIER_CONTROL_V01.md` now shows that the graded-coupling result survives the missing random-selection control. `BENCHMARK_SCOPE_V01.md` and `POLE_CONTAINMENT_V01.md` then sharpen the benchmark: the graph is itself exactly a pole bank, so the contest must be about **parameterization / hardware efficiency**, not a claim that geometry escapes the free-pole function class.
