# Material-adjoint derivation v0.1

The quasi-active HCN branch changes a different physical parameter from the earlier structural-bond experiments, but its local sensitivity has the same forward × return factorization.

This note is an algebraic consequence of the frozen linear frequency-domain model. It is not a biological learning claim.

## Harmonic system

For one frequency `omega`, the complete minimal quasi-active model is written

```text
A(d, omega) x_j = b_j
```

where `b_j` is a unit drive at injection site `j`, `x_j` is the complex field over the arbor, and

```text
A(d,omega)
  = A0(omega)
    + diag[d_i * c(omega)]

c(omega) = 1 + mu * a_h(omega)
```

with `a_h` the discrete first-order restorative-gate transfer.

The soma transfer for source `j` is

```text
H_j = e_s^T x_j.
```

## Derivative with respect to one local material density

Differentiate

```text
A x_j = b_j
```

with respect to real density parameter `d_i`:

```text
A (dx_j/dd_i) + (dA/dd_i) x_j = 0
```

so

```text
dx_j/dd_i
  = - A^-1 (dA/dd_i) x_j.
```

Because density enters only the local diagonal,

```text
dA/dd_i
  = c(omega) e_i e_i^T.
```

Therefore

```text
dH_j/dd_i
  = - e_s^T A^-1 e_i
      c(omega)
      e_i^T x_j.
```

Define the transpose/adjoint transfer field

```text
A^T y = e_s.
```

Then

```text
             local return      local forward
                 |                 |
                 v                 v

dH_j/dd_i = - c(omega) * y_i * x_{j,i}.
```

This is the same local factorization that appeared for bond conductances, now applied to **electrical material density** rather than anatomy.

## Reciprocity

In the current quasi-active model:

- the graph Laplacian is symmetric;
- damping/restoring terms are scalar/diagonal;
- quasi-active material is diagonal.

Therefore

```text
A^T = A
```

although `A` is generally complex and is not necessarily Hermitian.

So the transpose field `y` is generated by the **same frequency-domain medium** driven from the soma. Reciprocity again makes transpose propagation physically cheap.

If a future biological/engineering model adds direction-dependent or nonsymmetric couplings, the correct object remains `A^T`; same-medium reverse propagation is no longer guaranteed to equal it.

## Real scalar objective

For an example differentiable target

```text
J_j = |H_j - T_j|^2,
```

with real material parameter `d_i`,

```text
dJ_j/dd_i
  = 2 Re[ conj(H_j - T_j) * dH_j/dd_i ]

  = -2 Re[
        conj(H_j - T_j)
        c(omega)
        y_i
        x_{j,i}
      ].
```

A multi-source / multi-frequency objective is just the sum of these local terms.

Thus a local material tuner needs no global copy of the full arbor state after the forward and transpose fields are physically present. It can accumulate a local overlap, exactly as in the earlier physical-adjoint structural branch.

## Why this matters if the HCN confirmation passes

The current HCN experiment hand-imposes a smooth soma-to-distal density profile.

But CA1 HCN1 spatial distribution is known to be activity dependent and reversible, so the more interesting computational question is not whether we can manually draw a useful gradient. It is whether a local learning protocol can **discover a useful electrical-material profile from an initially uniform distribution**.

The algebra above means that experiment does not require inventing a new global learning mechanism. The same reciprocal-medium idea can provide the local sensitivity of channel/material density.

## Next candidate experiment

If the held-out quasi-active HCN gradient confirms:

1. freeze one or two frequencies and the same source-location ensemble;
2. start with uniform `d_i` under a fixed total-density budget;
3. choose a differentiable soma-coordination objective;
4. compute the exact material gradient with the local factorization above;
5. project updates back onto nonnegative density with fixed total material;
6. compare the learned profile with:
   - the hand-imposed distal gradient,
   - shuffled profiles,
   - an unconstrained digital optimizer;
7. only **after learning**, measure correlation of learned `d_i` with graph distance.

A distal-enriched profile would be an output of the optimization, not an assumption.
