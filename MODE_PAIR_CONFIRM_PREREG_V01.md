# Soma cross-term mode-pair confirmation v0.1 — preregistration

This confirmation is frozen after inspecting discovery seeds 72-83 from `MODE_PAIR_DISCOVERY_PREREG_V01.md` / `mode_pair_discovery_probe.py`.

## Held-out bodies

Use previously unseen FunctionalArbor bodies:

```text
seeds       84-95
lag         20
steps       210
source gain A/B = 1/1
```

The full graph-Laplacian basis is used for each connected 70-cell body. No growth, wave, source, gain, pulse, lag, soma, or readout parameter is changed.

## Discovery pattern being tested

The discovery set gave an unexpectedly specific picture:

- only about 1.1% of unordered mode pairs contained 50% of absolute order-sensitive cross-term mass;
- about 4.6% contained 80%;
- participation-ratio effective pair fraction was about 2.6%;
- diagonal `n=n` pairs carried only about 3% of absolute pair mass;
- mode 0, the unique constant graph mode, was the largest mean-involvement mode (~19% involvement);
- interactions involving mode 0 accounted for roughly one third of pair mass;
- modes 0-17 carried about 75% of total mode involvement;
- the previously confirmed direct-readout band 18-20 was *not* enriched in the soma cross-term decomposition (mean enrichment ~0.73).

This suggests a new mechanism: the energy-dominant common mode may be mostly order-blind when read alone but act as a reference/mixer through quadratic cross terms with nonconstant modes at the soma.

## Definitions

As in discovery, construct the exact ordered pair matrix at the target and distractor coherent soma-power peak times,

```text
M_nm = 2 Re[u_A,n(t_T) conj(u_B,m(t_T-tau))]
       - 2 Re[u_B,n(t_D) conj(u_A,m(t_D-tau))].
```

Convert to unordered contributions

```text
U_nn = M_nn
U_nm = M_nm + M_mn, n<m.
```

All concentration metrics use `|U|`.

Mode involvement assigns an off-diagonal pair half to each member and a diagonal pair fully to that mode, then normalizes by total absolute pair mass.

`mode0_pair_abs_fraction` is the fraction of total absolute unordered-pair mass in all pairs `(0,j)`, including `(0,0)`.

## Registered predictions

### P1 — decomposition identity

Mean relative reconstruction error for both the single-source modal sum and pair cross-term sum must be `< 1e-10`.

This is an implementation check, not a biological result.

### P2 — sparse pair support

All three held-out means must satisfy:

```text
pair fraction for 50% mass       < 0.020
pair fraction for 80% mass       < 0.070
effective pair fraction (PR)     < 0.050
```

### P3 — cross-mode rather than same-mode interaction

Mean diagonal absolute-pair fraction must be

```text
< 0.060.
```

Thus >94% of absolute pair mass should come from `n != m` interactions.

### P4 — constant-mode hub

All three must hold:

```text
mean mode-0 involvement fraction        > 0.150
mean mode-0 pair absolute fraction      > 0.300
mode 0 is the highest mean-involvement mode index across bodies
```

Mode 0 is unique for a connected graph, so this prediction is not vulnerable to rotations among degenerate nonconstant eigenspaces.

### P5 — low-spectrum concentration

Mean total involvement of modes `0..17` must be

```text
> 0.700.
```

### P6 — old direct-readout band is not the soma mixer

For the fixed band `{18,19,20}`, mean involvement enrichment relative to dimensional share must be

```text
< 1.0.
```

This is deliberately a surprising prediction: the band that was informative under direct coherent modal readout need not be the band that dominates the local soma power cross term.

## Exploratory but frozen outputs

The script will also reconstruct pseudo-power traces after removing only mode-0/nonzero cross-source mixing, and with only diagonal or only off-diagonal cross-source terms. These are descriptive mechanism ablations because discovery did not provide preregistered effect-size thresholds for their contrast changes.

## Interpretation

If P2-P4 confirm together, the earned statement is not merely "some graph modes matter." It is:

> **The soma's order-sensitive coherent term is generated by a sparse set of predominantly cross-mode interactions organized around the constant mode as a mixing hub.**

That would give a precise role to the previously puzzling mode 0: large and order-blind alone, but potentially useful as a reference component under square-law readout.

Failure of P4 would specifically kill the common-mode-mixer interpretation even if pair sparsity itself survives.
