# Time-domain in-situ wall — generating the adjoint wave is not yet the same as measuring every internal gradient without memory

The photonic/acoustic prior-art connection is real, but the exact time-domain bond gradient in this repo contains one physical requirement that should not be hidden by the phrase “same-medium backpropagation.”

## 1. What `RECIPROCAL_ADJOINT_V01.md` actually proved

For the damped reciprocal wave update, the **adjoint field required by the exact bond gradient** can be generated by the same physical medium if the soma objective-derivative waveform is supplied in reversed task time.

That result is exact.

The local sensitivity is then schematically

```text
g_e = sum_n
      forward_edge_difference[n]
      * adjoint_edge_difference[n].
```

In the algorithm, the full forward trajectory is stored, the adjoint is run backward in task index, and the aligned products are accumulated.

## 2. A causal physical replay reverses the adjoint index

To realize the backward recurrence with a causal forward-running physical medium, define a real replay time `r` such that

```text
retro_field[r] = adjoint_field[T-r].
```

During that replay, the gradient product requires the corresponding forward sample

```text
forward_field[T-r].
```

at the same local bond.

So the physical local operation is not merely

```text
run the error waveform backward through the body.
```

It is

```text
obtain a time-reversed copy of the LOCAL forward bond history
and multiply it against the causally replayed adjoint bond history.
```

The simulation currently gets the first factor from stored arrays.

## 3. Why damping makes this nontrivial

The original damped dynamics are not naively time-reversal invariant.

Sending the original input waveform backward in time through the same damped medium does **not** automatically reconstruct the time-reversed internal forward trajectory. Reversing `t` changes the sign of the first-derivative damping term.

The adjoint replay identity works because the adjoint recurrence plus index reversal maps onto the same causal damped equation. That does not give a free time-reversed copy of the original forward state.

## 4. Difference from the strongest existing demonstrations

### Hughes et al. 2018 / Pai et al. 2023

TRIM and silicon in-situ backpropagation operate primarily with coherent **steady-state / carrier-frequency phasor fields** in interferometric photonic meshes. The forward and time-reversed/adjoint fields can be superposed and the cross term extracted from intensity measurements. There is no long BPTT state history that must be locally time-aligned sample by sample.

### Li & Mao 2024

The fabricated mechanical in-situ gradient is a static/quasistatic linear elasticity problem. The local spring gradient is the product of a forward elongation and an adjoint elongation, again without a long temporal history.

### Hermans et al. 2015

This is the closest time-domain precedent. They physically backpropagate time-varying errors through a reciprocal acoustic dynamical system by reversing external error/Jacobian signals. In their acoustic demonstration they train input/output masks; after the physical backward pass, gradients for the trainable parameters are computed from recorded signals. They explicitly note that the acoustic system properties could in principle be optimized but omit that for experimental simplicity.

So the combination

```text
time-domain internal wave-medium parameters
+ O(1)-pass reciprocal adjoint
+ fully local in-situ gradient accumulation
without distributed trajectory memory
```

is not something we should claim as already solved by those demonstrations.

## 5. The physical options

To obtain every local bond gradient in the current time-domain model, at least one of the following is needed.

### A. Local analog/digital forward-history memory

Each tunable bond records its forward difference history. During the adjoint replay it reads that history in reverse and accumulates the product locally.

This preserves the `O(1)` wave-pass advantage but adds memory and multiply-accumulate hardware per monitored bond.

### B. Boundary/time-reversal memory

Capture enough boundary/internal information to synthesize a genuine time-reversed forward field during the adjoint replay, analogous to a time-reversal mirror or phase-conjugate reconstruction.

In a lossy internal medium this is not automatically exact and may require gain/equalization or substantial sensing.

### C. Frequency-domain training

Represent the temporal task by a set of frequencies/phasors and use TRIM-like steady-state interference per frequency. Parseval/correlation identities could reconstruct a time-domain objective from frequency-domain gradient measurements.

Cost shifts from local trajectory memory to number of frequency points / coherent measurements.

### D. External recording + local update compiler

Record forward and backward observable histories at accessible ports, compute gradients externally, and send control updates back to the local tuners.

This is physically realistic but gives up the strongest “all-local analog training” claim.

### E. Perturbative/local-lock-in measurement

Dither local tuners with orthogonal tags/frequencies and demodulate the scalar objective response. This can estimate many gradients in parallel without adjoint-state storage, but adds modulation bandwidth, signal-to-noise limits, and ceases to be the exact two-pass adjoint mechanism.

## 6. This changes the hardware cost model

The physical-adjoint advantage should now be split into two separate claims:

```text
ADJOINT TRANSPORT COST
same reciprocal body generates the error field in O(1) wave passes

GRADIENT READOUT COST
must correlate that returned field with the correct forward local history.
```

For steady-state photonics the second term can be cheap interference/intensity sensing. For the current broadband/time-domain internal-coupling problem, it may require distributed temporal storage or a different measurement protocol.

That cost belongs explicitly in the compiler benchmark.

## 7. The clean next hardware research question

> **Can the time-integrated local forward x adjoint bond correlation be measured in situ with O(1) global wave experiments and without storing a full forward time trace at every tunable bond?**

That is now a more important hardware question than generic noise injection.

A constructive next direction is to derive a multi-experiment intensity identity — a time-domain analogue of TRIM — and see whether the required gradient integral can be encoded directly in locally integrated energy measurements using only global source waveform transformations and a small number of repeated trials.

If that identity exists, the dynamic internal-coupling architecture becomes much more compelling. If it does not, distributed memory/monitor cost is a real tax that steady-state photonic meshes avoid.
